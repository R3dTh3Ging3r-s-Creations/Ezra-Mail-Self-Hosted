# Community Conduct

Ezra Mail's community should feel like the product: calm, considerate, and
clear.

- Treat people with respect and assume good intent while evaluating technical
  claims by evidence.
- Protect privacy. Never post another person's mail, credentials, identifiers,
  private infrastructure details, or security disclosures.
- Give specific, actionable feedback without harassment, threats, personal
  attacks, or discriminatory language.
- Keep discussion relevant to the project and its users.

Project maintainers may edit or remove content, close participation, or report
conduct that threatens people, privacy, or project safety. Private conduct
concerns may be raised with the repository owner through a private GitHub
channel.
