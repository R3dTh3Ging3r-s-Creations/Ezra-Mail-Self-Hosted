# Ezra Mail roadmap

Current app version: **v0.8.2**. This is the public roadmap for
`Ezra-Mail-Self-Hosted`, an experimental source release.

## Implemented

- Agenda-first Today, a fixed morning brief, separate later updates and waiting ages.
- Gmail and Microsoft account workspaces, local rules, triage and draft assistance.
- A focused reader, remote-image controls and bounded attachment previews.
- Exact-review outgoing mail, activity history and trusted-device protection.
- PWA installation metadata, opt-in foreground alerts, encrypted Web Push transport,
  quiet-hour/attention controls and optional Telegram delivery.

Implementation and automated synthetic checks do not establish native browser,
physical-device, provider or workplace acceptance. No consumer or business support
promise follows from this source release.

## Remaining milestones

- [ ] **v0.8.0 — Notifications and installable clients**
  - Complete native desktop/iOS installation and actual notification-delivery
    acceptance, including browser/OS suppression and multi-device behavior.
  - Complete guided Windows and Ubuntu installation rehearsals.
- [ ] **v0.9.0 — Broader provider support**
  - Add provider presets with explicit capability and permission boundaries.
- [ ] **v0.9.9 — Modern UI/UX audit and product refinement**
  - Audit daily workflows, navigation, language, responsive behavior and accessibility
    after planned v0.9 capabilities are complete.
- [ ] **v1.0.0 — Self-hosted general availability**
  - Establish supported installation/update paths and a stable validated baseline.
- [ ] **Ezra Cloud**
  - A separate possible hosted offering with its own operational and privacy policies.
