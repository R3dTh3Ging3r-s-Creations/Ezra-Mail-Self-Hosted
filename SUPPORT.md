# Ezra Mail Support

Ezra Mail is currently an owner-operated private preview, not a hosted service
or generally available consumer product.

The sanitized public mirror is named `Ezra-Mail`. It is pre-1.0 self-hosted
software and does not create a support SLA, hosted-service commitment, or
sponsor program.

## Start here

- Product overview and current status: [README](README.md)
- Private deployment: [Deployment guide](docs/DEPLOYMENT.md)
- Account/provider setup: [Ezra Mail setup](docs/EMAIL_AGENT_SETUP.md)
- Trusted-device and recovery guidance: [Security policy](SECURITY.md)
- Planned work: [Roadmap](docs/EZRA_MAIL_ROADMAP.md)

For a reproducible software defect, use the repository's bug-report form and
remove all private data from screenshots and logs. Security or privacy concerns
must follow [SECURITY.md](SECURITY.md), not a public issue.

General installation support and public Discussions will be opened when the
guided installer and public-release gate are complete.
